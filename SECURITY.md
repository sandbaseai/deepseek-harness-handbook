# Security policy

This repository contains documentation and examples, not a hosted DeepSeek Harness runtime.

Please do not publish API keys, session logs, credentials, private workspace paths, or vulnerability details in a public issue. Report a vulnerability involving repository scripts or examples through GitHub's private vulnerability reporting for this repository. For vulnerabilities in DeepSeek Harness itself, follow the official project's security process.

Third-party tools, plugins, model providers, and community projects mentioned here are discovery resources, not security endorsements. Review source, package scripts, permissions, network access, subprocess behavior, data retention, and compatibility before installation.
