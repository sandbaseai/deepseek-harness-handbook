Source narrows; dumps connect.

The pinned rc.2 production tree contains no Atomics.wait() or execSync(). Its production spawnSync() sites are bounded to paths such as sandbox probes, plugin installation, and Windows process-tree termination. Zstandard append uses promisified node:zlib. None of those facts proves the cause—but they prevent package names from becoming unsupported conclusions.
