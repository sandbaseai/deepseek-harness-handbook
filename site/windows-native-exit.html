Preserve command resolution, exact versions, timestamps, PID/parent PID, standard streams, and the first error. Redact credentials, signed URLs, prompts, and private paths before sharing.

Correlate three evidence planes.

Process treeWho owned the exit?

Executable path, PID, parent PID, creation time, non-secret argument shape.

Windows Error ReportingWhat failed natively?

Faulting application/module, exception, report id, subcode, and stack.

Harness durabilityWhat committed first?

Last Session sequence and whether tool admission, execution, or result persistence crossed its boundary.

One-variable A/BWhat changes the outcome?

Node, DSH artifact, profile, plugin, or action—change one, keep the rest fixed.

A dump is evidence and sensitive data.

procdump.exe -accepteula -ma -e <confirmed-pid> <private-dump-dir>
Attach only to the confirmed process.

Use an approved Microsoft Sysinternals binary. Keep dumps encrypted and access-controlled; they can contain API keys, prompts, files, environment values, registry data, and network material. Never upload them publicly.

Twelve gates before claiming a cause.

statusDecimal + hex.

Preserve unsigned eight-digit representation.

identityExact executables.

Prove dsh, Node, package manager, shell, and wrapper resolution.

lineagePID + parent PID.

Name the process that actually terminated.

WEROne correlated event.

Match timestamp, application, module, exception, and report id.

dumpSubcode + stack.

Do not infer either from the numeric status.

A/BOne changed variable.

Do not reinstall or reset several ownership layers together.
