Ownership

One UI owner. Two working contexts.

ChildNames the missing decision

ParentReviews and asks

ContinuationDelivers once

Durable relay

Commit the answer before delivery.

01Request

Validate version, question id, options, size, and child ownership.

02Present

Ask from the root Session and let the user answer, cancel, or expire.

03Commit

Persist one terminal human outcome before contacting the child.

04Resume

Deliver idempotently, then record child acknowledgement or replacement.

A clarification is not a permission grant.

Never use a generic user answer to expand sandbox, credentials, network, or tool authority.

Lifecycle choice

One-shot work cannot receive a second turn.

Use a continuable child when clarification is expected. Otherwise ask the parent, then start a replacement child with reviewed state.
