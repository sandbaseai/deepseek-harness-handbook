The invariantA finalized assistant message with zero tool-call blocks completes the step. With no pending inbox input, the ordinary turn closes.

Thirty seconds to containment.

  1. Cancel the active turn.Press Esc or Ctrl+C in the running TUI. Send Ctrl+C to a foreground CLI process.
  2. Watch the real meter.Confirm the process and provider usage stop. A frozen screen is not proof.
  3. Copy the trace.Preserve Session events, terminal output, timestamps, and sanitized provider usage.
  4. Do not resume unchanged.Fix the reachable failure or narrow tools, task, and budget before a fresh Session.

First, count the shape.

01 · one streamRepeated text chunks

Generation or adapter boundary. One request is not yet an Agent loop.

02 · many turnsFind every wake

Join each new turn to its user, Goal, plugin, or policy source.

03 · many stepsFind continuation input

Join each step to tool results, next-step input, or a turn-stopping hook.

04 · one durable messageCheck projection

A UI can repeat one message without making another provider request.

Stop actionless automation at its owner.

scopeAutomatic sources only

Never block a legitimate user-facing explanation, refusal, or final answer.

countZero finalized calls

Also require zero owned durable transition and no goal completion or question.

keyLifecycle + source + revision

Reset only on proven action or authenticated human input.

thresholdPause the owner

Leave the Agent idle. Never fabricate a tool call to force progress.

Prove the diagnosis with four cases.

  1. Fresh SessionSame route, same tool, short context.
  2. Long contextReconstruct compaction-sized context without private data.
  3. Goal disabledRun the same prompt without automatic Goal rounds.
  4. Control routeUse a known tool-capable model/provider route.
