Add one narrow hint.

GenericCallView {
  card: 'generic'
  kind: 'execute'
  rawInput: 'print("hello")'
  language: 'python'
}
It isPresentation

A banner and syntax grammar hint owned by the tool that produced the call view.

It is notAuthority

It cannot choose the runtime, executable, sandbox, permission, tool, or policy.

Require the semantic tuple.

card: generic+kind: execute+rawInput: string+language: non-empty→Code row

A language string alone cannot switch card families. Unknown grammar identifiers retain the banner and fall back to plain text; they never trigger an arbitrary dynamic import.
