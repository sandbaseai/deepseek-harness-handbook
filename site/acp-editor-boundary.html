The category errorPlans and tool cards are presentation. Stable call identity, terminal status, and token usage are control-plane facts.

What crosses the boundary today.

Committed content

Non-empty text and image blocks become agent_message_chunk updates.

Stop reason

The prompt response settles after the Agent becomes idle.

Cancellation

An addressed prompt can stop without cancelling another Session.

One-shot permission

A machine client can allow or reject a bridge-owned escalation.

What automation cannot reconstruct.

Executiontool lifecycle

No correlated call, progress, result, failure, or cancellation event.

Accountingturn usage

No runtime-owned input, output, cache, or reasoning token receipt.

Continuitysession resume

No list, load, resume, fork, or per-Session close contract.

Do not parse prose or tail JSONL remotely.

A model gateway can provide an explicit accounting workaround. Durable logs require shared filesystem access and are not an ACP compatibility surface.

The minimum observable bridge.

Project tool/call to tool_call, preserve its call id through one terminal tool_call_update, and normalize message usage into the prompt response or usage_update. Apply an explicit redaction and retention policy to raw inputs and outputs.

Acceptance gates.

Stable identity

Every tool starts and terminates exactly once.

Safe payloads

Arguments and results follow declared redaction rules.

Cost parity

Usage reconciles with provider accounting.

No UX inflation

Machine telemetry does not imply a native editor experience.
