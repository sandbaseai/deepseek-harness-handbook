Route the exact signature.

01 / FRAMEfirst frame is not exactly one header line

Quarantine one artifact. Generic recompression changes the format.

02 / SEQUENCEseq gap in committed region

Find duplicate writers before touching durable event numbers.

03 / IDENTITYinvalid message or duplicate start

Identify the producer or reused call identity before editing a healthy frame stream.

04 / READolder history silently disappears

Capture request, response, base cursor, and durable range before believing exhaustion.

Choose the least destructive outcome.

Proof gates.

  • Healthy sessions stay visible.
  • Bad path is identified.
  • Header owns one frame.
  • Committed seq is contiguous.
  • One session has one writer.
  • Read failures retain the last cursor.
  • Aborted prefixes survive cold reload.
  • Projection failure preserves raw range access.
