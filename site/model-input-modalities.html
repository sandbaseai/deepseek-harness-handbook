The rc.2 editor keeps model drafts structurally open, so an unrelated visible edit is intended to preserve hidden fields such as input. Removing a row, resetting the model array, or replacing the provider still removes its data deliberately.

Six proof gates.

  • 01The resolved profile names the exact provider and model.
  • 02The model declares both text and image after resolution.
  • 03A disposable UI edit preserves the hidden field.
  • 04Reload shows the same model row and selected route.
  • 05A fresh Session accepts one synthetic small image.
  • 06The intended endpoint receives and accepts that request.
A YAML write is not a capability test.

If the provider rejects the image, remove the incorrect claim. Do not disable attachment validation or broaden every model through defaultInput.
