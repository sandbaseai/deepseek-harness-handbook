rc.8 checks only the first byte, so it can return a shortened path and produce a downstream ENOENT. Reports now confirm both 开 U+5F00 → 00 5F and 销 U+9500 → 00 95. Regression fixtures must contain actual U+XX00 code points; “some CJK text” is not sufficient.
