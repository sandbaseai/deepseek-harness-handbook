Start with the product you are shipping.

DeepSeek Harness

Compose and ship the runtime graph: providers, Agent Loop, tools, policy, Sessions, and interfaces.

Claude Code

Give Claude a governed coding workspace and extend it with CLAUDE.md, Skills, MCP, hooks, agents, and plugins.

Codex

Use a repository-aware coding agent across local and hosted workflows with AGENTS.md, Skills, MCP, plugins, sandboxing, and approvals.

Hybrid

Use a coding agent to build DSH extensions, or expose shared services through MCP.

Do not translate names literally.

Session / threadstate contract

Carry a reviewed summary and artifacts, not a copied transcript.

Plugin / Skill / MCPextension contract

Rebuild discovery, activation, policy, and removal for the target.

Sandbox / permissioneffect contract

Test filesystem, network, process, escalation, and admin policy separately.

No universal winner.

Choose Claude Code or Codex when the coding-agent product is the desired boundary. Evaluate DeepSeek Harness when your deliverable is the inspectable, replaceable control plane itself.
