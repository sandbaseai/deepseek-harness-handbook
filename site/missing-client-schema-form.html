Do not run an unversioned pnpm add ...@next in the working profile.

The tag is mutable, the available package line trails rc.8, and a second internal runtime copy can turn one missing import into split Harness state.

Recover in a disposable profile.

dsh plugin --profile schema-form-probe add <plugin>@<reviewed-version>
dsh --profile schema-form-probe

Prefer a compatible plugin release or supported DSH distribution. If you deliberately test the standalone package, pin the exact version in the probe only, verify one coherent runtime closure, and require boot, settings, reload, and restart.
