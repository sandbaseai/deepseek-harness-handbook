Route deliberately.

Passthrough

Only when the exact route declares the media, transfer form, semantics, and limits.

Extract or hybrid

Use bounded parsing for stable citations; combine it with native visual/audio understanding when required.

Fail closed

Keep a human-only card or return an actionable refusal when no safe consumer exists.

Tell the truth about media.

PDFText is not the rendered page

Record native text, OCR, page images, coordinates, omissions, and truncation separately.

VideoSuccess is not full observation

Record frame sampling, audio, subtitles, timestamps, and any events the route can miss.

Six high-value release gates.

  • 01A provider file id never replaces the durable attachment identity.
  • 02Bindings are scoped to endpoint, account, API, model route, and digest.
  • 03Reconnect cannot duplicate a pending provider upload.
  • 04Route changes force safe re-planning instead of stale-id reuse.
  • 05PDF evidence declares text, OCR, rendering, citations, and truncation.
  • 06Video evidence declares frames, audio, subtitles, and sampling.
